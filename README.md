# Antojos Paisas

Aplicación PHP para menú, pedidos, caja y administración del negocio. La configuración de base de datos y pasarela se entrega únicamente por variables de entorno; los datos operativos no forman parte del repositorio.

## Inicio

1. Copia `.env.example` a `.env` y completa los valores del entorno.
2. Ajusta el servicio MySQL indicado en `docker-compose.yml`.
3. Ejecuta `docker compose up --build`.
